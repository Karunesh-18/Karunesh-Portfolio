# Surface brief: portfolio home

Mode: Experience. Audience: recruiters. Action: open a project, download resume, email.

## Direction contract
THESIS: The page is a patch panel, the physical place where network and cloud work gets plugged together. Refuses the dev-portfolio default of terminal prompt, neon glow and card grid. Seed ed92727f, assigned index 3, own derivation: network rack / patch panel (resume lists Packet Tracer, AWS VPC, subnetting, SSL/TLS, load balancing).
OWN-WORLD: Matte graphite rack ground (#14161a), brushed-steel rails, label-maker white strips, patch-cable jacket colors as the only saturated color (cobalt, orange, yellow, green) each owned by one project. Big Shoulders Display for rack labels, Schibsted Grotesk body, JetBrains Mono only for real data (repo names, dates, languages). Ports are square with LED dots.
STORY: Karunesh builds and deploys full-stack systems end to end. Visitor sees four real projects as live cables, believes the breadth through the repo table, then emails or downloads the resume.
FIRST VIEWPORT: Left rack-ear rail with nav and LEDs. Name in huge condensed caps filling the width. WebGL shader behind it: faint grid of cables with packets travelling. Bottom-right: resume download and email as two plug-shaped buttons. No eyebrow, no stats.
FORM: Patch panel, candidate 3 of own list (terminal, editorial studio, patch panel, Grafana wall, git graph, rail signage, PCB).
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
